# 🛍️ Customer Shopping Behavior Analysis | Data Analyst Portfolio Project

This project demonstrates an end-to-end data analytics workflow using **Python, SQL Server 2022, and Power BI** to analyze customer shopping behavior and generate meaningful business insights.

The project focuses on understanding customer purchasing patterns, product performance, discount usage, subscription behavior, shipping preferences, and revenue contribution across different customer segments.

It covers the complete analytics process, from data preparation and SQL-based analysis to interactive dashboard development and business reporting.

This project is suitable for:

- 📊 Data Analyst aspirants building a portfolio for internships and placements.
- 📚 Students learning Python, SQL Server, and Power BI.
- 💼 Candidates preparing for Data Analyst and Business Analyst interviews.
- 📈 Anyone interested in customer analytics and data-driven decision-making.

---

## 📌 Project Overview

The objective of this project is to analyze customer shopping data and answer important business questions that can help retailers understand customer behavior and improve their decision-making.

The project consists of four major stages:

### 🐍 1. Data Preparation and Analysis — Python

Python and Pandas are used to load, inspect, clean, and prepare the customer shopping dataset.

Key activities include:

- Importing the customer shopping dataset.
- Exploring data structure and summary statistics.
- Identifying and handling missing values.
- Standardizing column names.
- Creating additional analytical features, including age groups and purchase-frequency intervals.
- Preparing the dataset for SQL analysis.

### 🗄️ 2. Business Analysis — SQL Server 2022

SQL Server 2022 is used to store the prepared dataset and answer business questions through SQL queries.

The analysis covers:

1. Revenue generated by male and female customers.
2. Customers who used discounts but spent at least the average purchase amount.
3. Top five products with the highest average review ratings.
4. Average purchase amount comparison between Standard and Express shipping.
5. Average spending and total revenue of subscribers versus non-subscribers.
6. Products with the highest percentage of purchases using discounts.
7. Customer segmentation into New, Returning, and Loyal customers.
8. Top three most-purchased products within each category.
9. Repeat buyers grouped by subscription status.
10. Revenue contribution of different age groups.

SQL concepts used include:

- `SELECT`, `WHERE`, and `GROUP BY`
- Aggregate functions such as `SUM()`, `AVG()`, and `COUNT()`
- Subqueries
- `CASE` statements
- Common Table Expressions (CTEs)
- Window functions such as `ROW_NUMBER()`
- Sorting and filtering
- Numeric formatting using `CAST()`, `ROUND()`, and `DECIMAL`

### 📊 3. Interactive Dashboard — Power BI

Power BI is used to present the analysis through an interactive customer behavior dashboard.

**Key Performance Indicators (KPIs):**

- Number of Customers
- Average Purchase Amount
- Average Review Rating

**Visualizations:**

- Percentage of Customers by Subscription Status
- Revenue by Category
- Sales by Category
- Revenue by Age Group
- Sales by Age Group

**Interactive Filters (Slicers):**

- Subscription Status
- Gender
- Category
- Shipping Type

The dashboard allows users to explore customer behavior across different segments and compare purchasing patterns interactively.

### 📝 4. Reporting and Business Recommendations

The final stage summarizes the SQL analysis and Power BI findings in a structured project report.

The report includes:

- Project overview and objectives.
- Dataset description.
- Tools and technologies.
- Data preparation methodology.
- SQL queries and their output screenshots.
- Power BI dashboard.
- Key findings.
- Business recommendations.
- Limitations and conclusion.

## 📊 Dataset Description

The project uses a customer shopping behavior dataset containing **3,900 records and 18 source columns**.

The dataset includes customer demographics, shopping preferences, product information, purchase amounts, reviews, discounts, shipping methods, and subscription information.

### Important Dataset Columns

| Column | Description |
|---|---|
| Customer ID | Unique customer identifier |
| Age | Customer age |
| Gender | Customer gender |
| Item Purchased | Product purchased |
| Category | Product category |
| Purchase Amount (USD) | Recorded purchase amount in USD |
| Location | Customer location |
| Size | Product size |
| Color | Product color |
| Season | Shopping season |
| Review Rating | Customer review rating |
| Subscription Status | Whether the customer has a subscription |
| Shipping Type | Selected shipping method |
| Discount Applied | Whether a discount was applied |
| Previous Purchases | Number of previous purchases |
| Payment Method | Payment method used |
| Frequency of Purchases | Customer purchase-frequency category |

The dataset also contains a promo-code indicator in the source data.

## 🚀 How to Run the Project

### Step 1: Download the Repository

Clone the repository to your local computer:

```bash
git clone <your-github-repository-url>
```

Navigate to the project directory:

```bash
cd Customer-Behavior-Analysis
```

Replace the repository URL and directory name with your actual GitHub repository details.

### Step 2: Run the Python Notebook

Open the Jupyter Notebook:

```text
Customer_Shopping_Behavior_Analysis.ipynb
```

Run the notebook cells in sequence to:

1. Import the required libraries.
2. Load the CSV dataset.
3. Inspect the data.
4. Handle missing values.
5. Prepare the analytical features.
6. Connect Python to SQL Server.

Install the required libraries if necessary:

```bash
pip install pandas numpy sqlalchemy pyodbc jupyter
```

### Step 3: Configure SQL Server 2022

1. Install and start SQL Server 2022.
2. Open SQL Server Management Studio (SSMS).
3. Connect to your SQL Server instance.
4. Create or select the `customer_behavior` database.
5. Load the prepared dataset into the `dbo.customer` table using the Python notebook.
6. Verify that the table and columns are available.

The development connection used in this project is:

```text
Server: localhost\SQLEXPRESS01
Database: customer_behavior
Table: dbo.customer
Authentication: Windows Authentication
```

Your server instance may differ depending on your installation.

### Step 4: Execute the SQL Queries

Open:

```text
customer_behavior_sql_queries.sql
```

Execute the queries in SSMS to reproduce the ten business analyses.

Review the result grids to understand the differences in purchasing patterns across customer segments.

### Step 5: Open the Power BI Dashboard

Open the Power BI report:

```text
customer_behavior_dashboard.pbix
```

If required:

1. Verify the SQL Server connection.
2. Select the `customer_behavior` database.
3. Load or refresh the `dbo.customer` table.
4. Check the dashboard visuals.
5. Test all slicers to confirm that the KPIs and charts respond correctly.

### Step 6: Review the Project Report

Open the final project report to review the methodology, SQL outputs, dashboard, findings, and business recommendations.

## 📈 Key Findings

The following findings are based on the SQL Server outputs generated during this project.

### 1. Revenue by Gender

| Gender | Total Revenue |
|---|---:|
| Male | 157,890.00 |
| Female | 75,191.00 |

Male records contribute a higher total purchase amount than female records in the query results.

### 2. Product Ratings

The five products with the highest average review ratings in the supplied SQL output are:

| Product | Average Rating |
|---|---:|
| Gloves | 3.86 |
| Sandals | 3.84 |
| Boots | 3.82 |
| Hat | 3.80 |
| Skirt | 3.78 |

Gloves have the highest average review rating among the listed products.

### 3. Shipping Comparison

| Shipping Type | Average Purchase Amount |
|---|---:|
| Standard | 58.46 |
| Express | 60.48 |

Express shipping has a higher average purchase amount than Standard shipping in the query results.

### 4. Subscription Analysis

| Subscription Status | Customer Records | Average Spend | Total Revenue |
|---|---:|---:|---:|
| No | 2,847 | 59.87 | 170,436.00 |
| Yes | 1,053 | 59.49 | 62,645.00 |

Non-subscribers account for more records and higher total purchase revenue. Average spending is relatively similar between the two groups.

### 5. Customer Segmentation

| Customer Segment | Number of Records |
|---|---:|
| New | 83 |
| Returning | 701 |
| Loyal | 3,116 |

The Loyal segment is the largest group under the project's previous-purchase classification.

### 6. Revenue by Age Group

| Age Group | Total Revenue |
|---|---:|
| Young Adult | 62,143.00 |
| Middle-aged | 59,197.00 |
| Adult | 55,978.00 |
| Senior | 55,763.00 |

Young Adult records contribute the highest total purchase amount among the four age groups.

*Note: These results represent the supplied SQL outputs. Total purchase amount should not be interpreted as profit, and differences between groups do not establish causation.*

## 💡 Business Recommendations

Based on the analysis, the following actions could be explored:

- **Category Performance:** Monitor revenue and sales across product categories to identify high-performing categories.
- **Subscription Strategy:** Test targeted subscription offers and compare conversion rates, repeat purchases, and average spending.
- **Discount Optimization:** Evaluate discount usage alongside sales volume and profit margins.
- **Shipping Analysis:** Compare shipping options using purchase amount, customer satisfaction, delivery cost, and conversion.
- **Customer Segmentation:** Use previous-purchase behavior to explore differences between New, Returning, and Loyal customers.
- **Age-Group Analysis:** Explore purchasing patterns by age group while treating the groups as dataset-specific segments.
- **Dashboard Monitoring:** Use interactive Power BI filters to investigate differences across customer demographics and shopping preferences.

These recommendations should be validated using additional business data before making operational decisions.

## ⚠️ Limitations

- The dataset does not include transaction dates, limiting time-series and seasonal trend analysis.
- Product costs and profit margins are not available, so profitability cannot be calculated.
- Average purchase amounts describe recorded purchase values and do not establish customer lifetime value.
- Some SQL screenshots show only a portion of the result grid.
- The dashboard KPIs depend on the selected slicer filters.
- Descriptive comparisons do not prove that subscriptions, discounts, or shipping methods cause changes in spending.
