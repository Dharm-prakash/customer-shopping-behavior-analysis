# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview
An end-to-end data analytics project to analyze customer shopping behavior, spending patterns, product preferences, and subscription trends.

## 🛠️ Tools Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL Server 2022
- Power BI

## 📊 Project Workflow
- **Python:** Data cleaning and exploratory data analysis (EDA).
- **SQL Server:** Business queries and customer behavior analysis.
- **Power BI:** Interactive dashboard for visualizing key insights.

## 🔍 Key Analysis
- Revenue by gender and age group
- Popular products and categories
- Subscription and discount trends
- Customer segmentation
- Shipping preferences and repeat purchases

## 💡 Business Insights
The analysis helps identify customer segments, understand purchasing patterns, and support data-driven business decisions.

## 📁 Project Structure
- `Python/` – Data cleaning and EDA
- `SQL/` – SQL queries
- `PowerBI/` – Dashboard file
- `Dataset/` – Dataset
